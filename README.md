# 蠡歪直播监测站

前端由 GitHub Pages 发布到 https://liwai.flyou.cc，Cloudflare Pages Functions + D1 提供只读概览和分页历史。Ubuntu 继续负责全天监测并主动推送，不需要为本次改版修改服务或密钥。

## 界面

嵌入式深色计时屏、带凹槽进度条和按压反馈的实体卡片，以及悬浮玻璃导航。Chromium 中玻璃层使用圆角法线位移图对背景做边缘折射，其他浏览器使用模糊和高光降级。光学层与文字分离，支持减少动效和减少透明度。原有三套主题已移除。

- 实时概览：当前核验状态、计时、今日数据、近七日趋势。
- 日周报告：当日与本周统计。
- 历史台账：进入后按需加载；支持日期范围、10/20/50 条分页、单日详情。

首页只读取 `GET /v1/overview`，最多返回七条近期记录。每分钟刷新概览；隐藏页面暂停请求。短期缓存不带时间戳破坏缓存；浏览过的历史页在当前会话中缓存一分钟，最多十二页。API 失败或数据超过三分钟未更新时冻结计时并标明旧数据。

## 验证

线上仍直接发布根目录静态文件，无需构建。Node.js 24 下可运行检查：

```sh
node --test tests/*.test.mjs
node --check app.js
```

测试使用真实 SQLite 验证旧快照迁移、归档事务回滚、日期筛选、分页、乱序推送和十年数据量下的响应上限；前端测试覆盖按需请求、后台暂停、断线冻结、竞态与文本转义，不代替浏览器视觉测试。

本地预览（开发依赖不进入线上页面）：

```sh
npm ci
npm run dev
```

Cloudflare 设置、兼容性与自动迁移见 [cloudflare/README.md](cloudflare/README.md)。
