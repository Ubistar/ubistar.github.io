# 蠡歪 · 直播观察室

网站：https://liwai.flyou.cc 。GitHub Pages 发布静态前端，Cloudflare Pages Functions + D1 提供数据；Ubuntu 继续全天监测、每分钟推送。

## 3.0 界面

完整替换旧界面：流动曲面背景、透明玻璃信息模块、边缘折射与镜面高光。光学贴图改编自 [xiaojiaenen/liquid-glass](https://github.com/xiaojiaenen/liquid-glass)，采用 Snell 折射、圆角位移图和 SVG 背景滤镜。详见 [第三方声明](THIRD_PARTY_NOTICES.md)。

- **实时观察**：直播状态、连续计时、今日开播/未开播、本周出勤、连续缺席、七日时间切片、每日手记、历史档案与监测状态。
- **出勤报告**：7/30/90 天切换、开播曲线、日历热图、时长分布、完整日日均、最长营业日和前五名记录。
- **丰富详情**：桌面点击、手机长按 430ms、键盘 Enter/空格展开。手指移动或滚动取消长按。详情由原卡片非线性展开，关闭回到原位，异步统计渐变扩展，支持 ESC、焦点返回和减少动效。
- **历史台账**：按日期筛选，10/20/50 条分页，单日完整报告，历史重算单独标记。

Chromium 使用 SVG 背景折射；Safari/Firefox 使用透明模糊与高光兼容模式，iOS 上不承诺与 Chromium 完全相同的像素折射效果。用户开启减少透明度时提高背景遮罩。

## 静音直播背景

只在监测状态新鲜且正在开播时请求 `/v1/stream`。Cloudflare 解析固定房间的公开播放元数据，视频清单与分片由访客浏览器**直接向 Bilibili CDN 请求**，不经 Ubuntu 或本站转发。Safari 优先原生 HLS，其他支持 MSE 的浏览器按需加载本地 hls.js 1.7.3。播放器始终静音，可暂停/重试；隐藏页面暂停视频及请求。

视频采用 `object-fit: cover`，按实际窗口宽高比居中裁剪，不加黑边、不旋转内容。约每 650ms 对低分辨率视频帧的各模块对应区域采样，根据亮度与局部明暗范围调整文字和玻璃底色。标题区域同时保护对比度；无法读取跨域像素时使用稳定深色遮罩。

B 站播放地址、CDN 跨域策略、地区/防盗链限制和浏览器自动播放政策会影响实际播放。连接失败显示明确状态与重试入口，保留静态背景；不会将示例视频当成直播。没有登录态、密钥、视频代理或绕过限制的逻辑。首次发布验收时主播未开播，真实直播流的端到端播放仍需开播后确认。

## 数据与历史

首页仅请求紧凑 `/v1/overview`（最多七条日记录）；历史与区间统计在进入对应页面/详情时按需加载。当前会话缓存最多 16 个 API 请求结果，时效一分钟；每分钟只刷新概览，隐藏页面暂停请求。API 失败或源记录超过三分钟未更新时冻结计时，并标记旧数据；跨北京时间午夜不继续外推昨天的日统计。

改版不改变 D1 归档/补传规则、不清空旧日期，也不改 Ubuntu。空缺与真实零值分开显示；历史场次重算无法证明空白期间持续监测正常。原始窗口之外的恢复流程见 [数据桥说明](cloudflare/README.md)。

## 开发与验证

线上直接发布根目录静态文件，无需构建。

```sh
npm ci
npm run dev
npm test
python3 -m unittest discover -s tests -p 'test_backfill.py'
```

测试覆盖 SQLite 迁移/事务/补传/分页、十年历史响应上限、只读区间统计、缺失值与零值、断线计时冻结、请求缓存、长按取消、桌面与键盘交互、HLS 地址校验和横竖屏裁剪。浏览器视觉验收与真实直播播放验收独立于单元测试。

`vendor/liquid-physics.ts` 保留参考源文件，`lib/glass-maps.js` 为其无依赖 ESM 转译；`vendor/hls.light.min.js` 来自锁定的 hls.js 包，只有开播才加载。更新 hls.js 后同步复制发布包及许可证。
